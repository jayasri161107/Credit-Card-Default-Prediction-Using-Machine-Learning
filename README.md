Credit Card Default Prediction Using Machine Learning

Project Overview
This project focuses on analysing credit card customer data to identify patterns and factors associated with payment defaults using Python.

Objective
To perform Exploratory Data Analysis (EDA), preprocess the dataset, and prepare it for developing machine learning models to predict credit card defaults.

Dataset
The dataset contains 30,000 customer records, including:
- Customer demographics
- Credit limits
- Repayment status
- Monthly bill amounts
- Previous payment amounts
- Default payment status

Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Project Workflow
1. Data Loading and Inspection
2. Data Cleaning and Preprocessing
3. Handling Missing Values and Duplicates
4. Exploratory Data Analysis
5. Statistical Analysis
6. Data Visualization
7. Outlier Detection and Treatment
8. Data Preparation for Machine Learning

Machine Learning
Future implementation includes classification algorithms to predict customer payment defaults and evaluate model performance.
